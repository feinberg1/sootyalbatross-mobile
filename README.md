# Save the Sooty Albatross

An interactive Species Survival Plan game for the Sooty Albatross (*Phoebetria fusca*) on South Africa's Prince Edward Islands (Marion Island and Prince Edward Island).

Find the five problems threatening the albatrosses, meet the helpers who know how to solve each one, and put every solution into action before the population runs out.

## Play

Open `index.html` in any web browser, or visit the GitHub Pages link for this repository.

All sources, including photo credits, are listed in the game under the **Sources** button.
